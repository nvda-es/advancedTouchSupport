# Advanced touch support add-on for NVDA

* Author: Asociación Comunidad hispanohablante de NVDA
* NVDA compatibility: NVDA 2025.3.3 and beyond

## Introduction

This add-on allows you to configure some advanced features that may improve your interaction with a touch screen when it has an uncommon size or a non-standard screen resolution.

## How to use

Once installed, go to NVDA menu > Preferences > Settings > Advanced touch support category. The following settings are available:

* Minimum flick size (in pixels): minimum distance that a finger must move before NVDA interprets the gesture as a flick. Defaults to 50 pixels. You may want greather values on low resolutions and smaller ones on large screens. Configure until you feel comfortable.
